**W2-PM1 – Footprinting with Multiple Kali Linux Tools**

**Objective**

To understand footprinting and reconnaissance by gathering publicly available information about a domain using Kali Linux tools.

**Tools Used**
- WHOIS
- WhatWeb
- NSLookup
- cURL
- WAFW00F
- DNSRecon

**Practical Evidence**

Screenshots and command outputs from all six practical tasks will be uploaded to this folder.

**Conclusion**

This practical helped me understand how reconnaissance tools identify domain registration details, website technologies, DNS records, HTTP headers and web application firewall information.
