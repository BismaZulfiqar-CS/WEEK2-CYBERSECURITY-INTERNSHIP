**W2-PM5 – Network Scanning with Zenmap**

**Objective**

To understand network scanning and host discovery using Zenmap and identify active devices connected to a local network.

**Tools Used**
- Zenmap
- Nmap
- Windows Command Prompt

**Tasks Completed**
1. Downloaded and installed Zenmap on Windows.
2. Identified the local IP address and LAN subnet using the `ipconfig` command.
3. Performed a Ping Scan to discover active hosts within the local network.
4. Identified the number of live hosts.
5. Recorded the IP addresses of discovered hosts.
6. Identified MAC addresses where available.
7. Generated and saved the network topology in PDF format.

**Practical Evidence**

Screenshots of the installation, network configuration, scanning results and network topology will be included in this folder.

**Key Learning Outcomes**
- Understanding network scanning.
- Identifying active hosts on a local network.
- Understanding IP and MAC addresses.
- Using Zenmap to perform Ping Scans.
- Interpreting network scanning results.
- Generating network topology diagrams.

**Conclusion**

This practical provided hands-on experience with Zenmap and network discovery. I learned how to identify active devices, examine network information and generate a visual representation of network topology.

All scanning activities were conducted within my own authorised network environment.
