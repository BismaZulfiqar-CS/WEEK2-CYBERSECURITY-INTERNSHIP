**Project Overview**

During Week 2, I completed four practical project modules using different cybersecurity tools and techniques. These activities helped me understand how security professionals gather information about domains, identify website technologies, investigate digital footprints and discover devices connected to a network.

**Modules Completed**

**W2-PM1 – Footprinting with Multiple Kali Linux Tools**

Explored domain information and website infrastructure using six Kali Linux tools.

**Tools:** WHOIS, WhatWeb, NSLookup, cURL, WAFW00F and DNSRecon.

**W2-PM3 – Footprinting with Maltego**

Practised visual reconnaissance and information gathering using Maltego to explore relationships between digital entities.

**W2-PM4 – Footprinting with theHarvester**

Practised reconnaissance and information gathering using theHarvester to identify publicly available information associated with a target.

**W2-PM5 – Network Scanning with Zenmap**

Used Zenmap on Windows to discover active devices within my local network, identify IP and MAC addresses where available, and generate a network topology.
